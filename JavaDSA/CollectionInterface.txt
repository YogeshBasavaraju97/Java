
Java Collection framework is collection of interfaces, classes, and algorithms used to store retrive, manipulate 
and process group of object
In simple words:
Collection Framework = A predefined set of interfaces and classes that helps us manage multiple objects efficiently.

Why do we need Collections?

Before collections, developers commonly used arrays.

Arrays have limitations:
- Fixed size.
- Difficult to insert or delete elements.
- Limited built-in operations.
- Less flexible for dynamic data.
Collections solve these problems by providing dynamic data structures.


Important characteristics
- Dynamic storage.
- Ready-made data structures.
- Searching and sorting.
- Insertion and deletion.
- Iteration.
- Reusable algorithms.
- Type safety through Generics.


The framework has two important branches:
1. Collection hierarchy
2. Map hierarchy

The Main interfaces are
List - stores duplicate elements and maintain insertion order
Set  - Stores unique elements
Queue - Processes elements in queue order

Map - Stores key value pair
